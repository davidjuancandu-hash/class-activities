📋 Teacher instructions and shortcuts

Ask a student to define the displayed word out loud. Click Reveal Definition, compare the response to the model definition, and ask for an original example. Click Next Word to continue. Definitions are hidden again for each new word. Use Shuffle all 40 for random order without repeats. Changing the order or clicking Start Over begins a fresh round.

Keyboard: Space = reveal, → = next after reveal, ← = previous. The game works offline if you save this page locally.

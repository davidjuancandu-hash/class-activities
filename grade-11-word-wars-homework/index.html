📘 Thinking Guide (help without answers)

Read each question carefully. For written answers, state your opinion, give a reason using because, and include an example. A word chain works like CAT → TIGER → RABBIT.

For definitions, think about how the word is used in a real sentence. For pronunciation, practice saying the word out loud before answering.
